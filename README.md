# Express Blog API with CRUD, Controllers, and Middleware

## Descrizione
Questo progetto è un’evoluzione del blog realizzato con Express.js, in cui vengono introdotti concetti avanzati come **CRUD**, **controllers** e **middleware**.  
Permette di gestire i post del blog tramite un’API REST, separando la logica in moduli organizzati.

Si basa sulle repo precedenti:
- [Express Blog Intro](https://github.com/mendozagianfranco/express-blog-intro)
- [Express Blog Routing](https://github.com/mendozagianfranco/express-blog-routing)

Funzionalità principali:
- Gestione dei post tramite API RESTful.
- Operazioni CRUD (Create, Read, Update, Delete) sui post.
- Separazione della logica in **controllers** per ogni operazione.
- Uso di **middleware** personalizzati per validazioni o gestione degli errori.
- Rotte organizzate per una migliore manutenibilità.
- Servizio di file statici con `express.static`.

---

## Tecnologie utilizzate
- Node.js
- Express.js
- JavaScript (vanilla)
